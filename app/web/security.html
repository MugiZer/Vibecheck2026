Upload security, proved in Lean

Five theorems about the upload gate. make verify checks each one with lake comparator against the statements in Verification/Challenge.lean, and allows no axioms beyond Lean's standard three.

upload_ignores_client_nameThe file name a client sends never changes where its upload is stored.
upload_fixed_shapeEvery stored path is `uploads/<32 lowercase hex digits>/UserSpec.lean`, so it cannot leave `uploads/`.
upload_never_over_limitThe bytes the gate lets through never add up to more than the limit, for any chunking.
upload_accepted_iff_within_limitAn upload is accepted exactly when it fits: the limit is accepted, one byte more is rejected.
upload_accepted_writes_everythingFor an accepted upload, the gate passes every chunk through, in order (a statement about chunk sizes).

Not proved: the gate's file-system calls and read loop, the Python HTTP handler, and the sandbox that runs uploaded Lean. make check tests these through the real endpoints, for example an upload named ../../../../tmp/evil.lean and an upload one byte over the limit.

The code the upload gate runs

app/upload/Upload/Store.lean

The gate is a compiled Lean program. It calls destination and admit on every upload.

/-!
# Upload storage decisions

The upload gate uses these two functions on the real upload path. The proofs
in `Specs/UploadSpec` are about these exact functions.
-/

namespace Upload

/-- A lowercase hexadecimal digit: `0`-`9` or `a`-`f`. -/
def isHexDigit (c : Char) : Bool := ('0' ≤ c && c ≤ '9') || ('a' ≤ c && c ≤ 'f')

/-- A server-made upload id: exactly 32 lowercase hexadecimal digits. -/
def validId (id : String) : Bool := id.toList.length == 32 && id.toList.all isHexDigit

/-- The one file name every upload is stored under. -/
def storedName : String := "UserSpec.lean"

/-- Where an upload is stored: `uploads/<id>/UserSpec.lean`. The file name the
client sent is ignored on purpose, so it cannot choose the path. -/
def destination (id : String) (_clientName : String) : Option String :=
  if validId id then some ("uploads/" ++ id ++ "/" ++ storedName) else none

/-- What to do with the next chunk of an upload, given the bytes already
accepted: keep it and return the new total, or reject the whole upload. -/
def admit (limit used size : Nat) : Option Nat :=
  if used + size ≤ limit then some (used + size) else none

/-- Feed an upload's chunk sizes through `admit`, as the gate does. Returns the
chunks it lets the gate write, and whether the whole upload was accepted. -/
def gate (limit : Nat) : List Nat → Nat → List Nat × Bool
  | [], _ => ([], true)
  | c :: cs, used =>
    match admit limit used c with
    | some used' => let r := gate limit cs used'; (c :: r.1, r.2)
    | none => ([], false)

end Upload

Spec: an upload cannot choose where it is stored

Specs/UploadSpec/Destination.lean

import Upload.Store

/-!
# Spec: an upload cannot choose where it is stored

The client sends a file name. That name must have no effect on where the file
is written, and every path the server writes to must have one fixed shape.
-/

namespace UploadSpec

/-- Changing the file name the client sends never changes the destination. -/
def IgnoresClientName : Prop :=
  ∀ (id nameA nameB : String), Upload.destination id nameA = Upload.destination id nameB

/-- Every destination the server accepts is `uploads/<id>/UserSpec.lean`, where
`id` is 32 lowercase hexadecimal digits. Such an id holds no `/` and no `.`,
so the path has exactly three parts and cannot climb out of `uploads/`. -/
def FixedShape : Prop :=
  ∀ (id name path : String), Upload.destination id name = some path →
    path = "uploads/" ++ id ++ "/" ++ "UserSpec.lean" ∧
    id.toList.length = 32 ∧
    ∀ c ∈ id.toList, c ≠ '/' ∧ c ≠ '.' ∧ (('0' ≤ c ∧ c ≤ '9') ∨ ('a' ≤ c ∧ c ≤ 'f'))

end UploadSpec

Spec: an upload cannot be larger than the limit

Specs/UploadSpec/Limit.lean

import Upload.Store

/-!
# Spec: an upload cannot be larger than the limit

The gate reads an upload in chunks and asks `Upload.admit` about each chunk
before writing it. These statements are about `Upload.gate`, which feeds a list
of chunk sizes through `admit` in the same way.
-/

namespace UploadSpec

/-- The total of a list of chunk sizes. -/
def total (chunks : List Nat) : Nat := chunks.foldr (· + ·) 0

/-- The bytes the gate lets through never add up to more than the limit, for
any sequence of chunks. -/
def NeverOverLimit : Prop :=
  ∀ (limit : Nat) (chunks : List Nat), total (Upload.gate limit chunks 0).1 ≤ limit

/-- An upload is accepted exactly when its total size is at most the limit. A
file of exactly the limit is accepted; one byte more is rejected. -/
def AcceptedIffWithinLimit : Prop :=
  ∀ (limit : Nat) (chunks : List Nat),
    (Upload.gate limit chunks 0).2 = true ↔ total chunks ≤ limit

/-- When an upload is accepted, every chunk is written, in order. -/
def AcceptedWritesEverything : Prop :=
  ∀ (limit : Nat) (chunks : List Nat),
    (Upload.gate limit chunks 0).2 = true → (Upload.gate limit chunks 0).1 = chunks

end UploadSpec

The proofs, with good and bad examples

Specs/UploadSpec/Proofs.lean

Lean's kernel checks every proof and every example. A false example would stop the build.

import UploadSpec.Destination
import UploadSpec.Limit

/-! Proofs of the upload specs, with examples that meet every hypothesis and
examples of bad behaviour the specs rule out. -/

namespace UploadSpec
open Upload

theorem ignoresClientName : IgnoresClientName := fun _ _ _ => rfl

theorem fixedShape : FixedShape := by
  intro id name path h
  simp only [destination] at h
  split at h
  · rename_i hv
    cases h
    simp only [validId, Bool.and_eq_true, beq_iff_eq, List.all_eq_true] at hv
    refine ⟨by simp [storedName, String.append_assoc], hv.1, fun c hc => ?_⟩
    have hd := hv.2 c hc
    simp only [isHexDigit, Bool.or_eq_true, Bool.and_eq_true, decide_eq_true_eq] at hd
    refine ⟨?_, ?_, hd⟩ <;> rintro rfl <;> simp at hd
  · cases h

theorem gate_written_le : ∀ (limit used : Nat) (chunks : List Nat), used ≤ limit →
    used + total (gate limit chunks used).1 ≤ limit
  | _, used, [], h => by simpa [gate, total] using h
  | limit, used, c :: cs, h => by
    by_cases hle : used + c ≤ limit
    · have ih := gate_written_le limit (used + c) cs hle
      simp only [gate, admit, hle, ite_true, total, List.foldr_cons] at ih ⊢
      omega
    · simp [gate, admit, hle, total, h]

theorem neverOverLimit : NeverOverLimit := fun limit chunks => by
  simpa using gate_written_le limit 0 chunks (Nat.zero_le _)

theorem gate_accepts_iff : ∀ (limit used : Nat) (chunks : List Nat), used ≤ limit →
    ((gate limit chunks used).2 = true ↔ used + total chunks ≤ limit)
  | _, used, [], h => by simpa [gate, total] using h
  | limit, used, c :: cs, _ => by
    by_cases hle : used + c ≤ limit
    · have ih := gate_accepts_iff limit (used + c) cs hle
      simp only [gate, admit, hle, ite_true, total, List.foldr_cons] at ih ⊢
      rw [ih]
      omega
    · simp only [gate, admit, hle, ite_false, total, List.foldr_cons, Bool.false_eq_true, false_iff]
      omega

theorem acceptedIffWithinLimit : AcceptedIffWithinLimit := fun limit chunks => by
  simpa using gate_accepts_iff limit 0 chunks (Nat.zero_le _)

theorem gate_accepted_all : ∀ (limit used : Nat) (chunks : List Nat),
    (gate limit chunks used).2 = true → (gate limit chunks used).1 = chunks
  | _, _, [], _ => rfl
  | limit, used, c :: cs, h => by
    by_cases hle : used + c ≤ limit
    · simp only [gate, admit, hle, ite_true] at h ⊢
      exact congrArg (c :: ·) (gate_accepted_all limit (used + c) cs h)
    · simp [gate, admit, hle] at h

theorem acceptedWritesEverything : AcceptedWritesEverything := fun limit chunks =>
  gate_accepted_all limit 0 chunks

/-! ## Examples -/

/-- A real id: traversal and absolute file names land in the same place as a plain one. -/
example : destination "0123456789abcdef0123456789abcdef" "../UserSpec.lean" =
    destination "0123456789abcdef0123456789abcdef" "spec.lean" := ignoresClientName _ _ _
example : destination "0123456789abcdef0123456789abcdef" "/etc/passwd" =
    some "uploads/0123456789abcdef0123456789abcdef/UserSpec.lean" := by decide
/-- Ids that are not 32 lowercase hex digits are refused. -/
example : destination "../../../../../../../../etc/passwd" "x" = none := by decide
example : destination "0123456789ABCDEF0123456789ABCDEF" "x" = none := by decide
example : destination "0123456789abcdef0123456789abcde/" "x" = none := by decide

/-- Limit 10: exactly 10 bytes is accepted, in any chunking. -/
example : gate 10 [4, 6] 0 = ([4, 6], true) := by decide
example : gate 10 [10] 0 = ([10], true) := by decide
/-- One byte over is rejected, and a chunk that crosses the limit is never written. -/
example : gate 10 [11] 0 = ([], false) := by decide
example : gate 10 [4, 7] 0 = ([4], false) := by decide
example : (gate 10 [4, 7] 0).2 = false := by decide
/-- The spec rejects a gate that would write a chunk crossing the limit. -/
example : ¬ (total [4, 7] ≤ 10) := by decide

end UploadSpec
